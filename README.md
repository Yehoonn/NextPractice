# Next.js 연습 프로젝트

이 프로젝트는 Next.js를 활용한 연습 프로젝트입니다.
Next.js의 기본 개념과 기능을 익히고, SSR(Server-Side Rendering), SSG(Static Site Generation), API Routes 등을 실습합니다.

## 📌 프로젝트 개요

- Next.js의 기본적인 설정과 사용법 익히기
- 페이지 라우팅 및 동적 라우팅 구현
- 서버사이드 렌더링(SSR)과 정적 사이트 생성(SSG) 실습
- API Routes 활용
- 스타일링 및 UI 라이브러리 적용

## 🛠 기술 스택

- **Framework**: Next.js
- **Language**: TypeScript / JavaScript
- **Styling**: Tailwind CSS / Styled-components
- **State Management**: React Context API / Redux Toolkit (선택 사항)
- **Database**: (필요 시 추가)

## 🚀 실행 방법

### 1. 프로젝트 클론

```bash
git clone https://github.com/Yehoonn/NextPractice.git
```

### 2. 패키지 설치

```bash
npm install  # 또는 yarn install
```

### 3. 개발 서버 실행

```bash
npm run dev  # 또는 yarn dev
```

- 기본적으로 `http://localhost:3000` 에서 실행됩니다.

### 4. 빌드 및 배포

```bash
npm run build
npm start
```

## 📂 프로젝트 구조

```
nextjs-practice/
│── pages/           # Next.js의 페이지 라우팅 폴더

```
